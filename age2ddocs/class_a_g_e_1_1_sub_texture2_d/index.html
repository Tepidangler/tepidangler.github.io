AGE::SubTexture2D::SubTexture2D (
    const Ref< Texture2D > & Texture,
    const Vector2 & Min,
    const Vector2 & Max
)

Parameters:

  • Texture A const reference to a Texture2D object. This is the texture that the subtexture will be created for.
  • Min A const reference to a Vector2 object. This represents the bottom-left corner of the subtexture within the parent texture.
  • Max A const reference to a Vector2 object. This represents the top-right corner of the subtexture within the parent texture.

Constructs a SubTexture2D object from a reference to a Texture2D, and two Vector2 coordinates.

The constructor initializes the texture member variable with the provided Texture2D reference. It also calculates the texture coordinates for the sub-texture based on the Min and Max vectors.

Parameters:

  • Texture A const reference to a Texture2D object.
  • Min A Vector2 representing the minimum x, y coordinates of the sub-texture in the texture atlas.
  • Max A Vector2 representing the maximum x, y coordinates of the sub-texture in the texture atlas.

function CreateFromCoords

Creates a subtexture from given texture at specified coordinates. 

static Ref< SubTexture2D > AGE::SubTexture2D::CreateFromCoords (
    const Ref< Texture2D > & Texture,
    const Vector2 & SpriteLoc,
    const Vector2 & CellSize,
    const Vector2 & SpriteSize=Vector2 {1.f, 1.f}
)

This function takes in Texture2D, Vector2 (SpriteLoc, CellSize, SpriteSize) to calculate the min and max UVs for SubTexture2D.

Creates a subtexture from given parameters.

This function takes in parameters that define a rectangular area within a larger texture and calculates the UV coordinates for this area. It then returns a new SubTexture2D object with these calculated coordinates.

Parameters:

  • Texture The main texture to create the subtexture from.
  • SpriteLoc The location of the sprite in the texture (in cells).
  • CellSize The size of each cell in the texture (in pixels).
  • SpriteSize The size of the sprite within a single cell (in cells).

Returns:

A reference to a new SubTexture2D object.
