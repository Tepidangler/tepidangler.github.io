)

This function retrieves the frame data for a given sprite name from the Aseprite data map. If the sprite does not exist in the map, an exception is thrown.

Parameters:

  • SpriteName The name of the sprite to retrieve the frame data for.

Returns:

Reference to the vector of frames associated with the given sprite name.

Exception:

  • std::out_of_range If the provided sprite name does not exist in the Aseprite data map.

Get the frame data of a specific sprite.

This function retrieves the frame data for a given sprite name from the Aseprite data map. If the sprite does not exist, it will return an empty vector.

Parameters:

  • SpriteName The name of the sprite to retrieve the frame data for.

Returns:

std::vector<AsepriteFrameData>& Reference to the frame data vector of the specified sprite. If the sprite does not exist, it will return an empty vector.
