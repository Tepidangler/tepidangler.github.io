function decode

Decodes a Node object into an AGE::Vector2 .

static inline bool YAML::convert< AGE::Vector2 >::decode (
    const Node & node,
    AGE::Vector2 & rhs
)

This function attempts to decode the given Node object into an AGE::Vector2. It checks if the node is a sequence and has exactly two elements, then assigns the first element of the node as x value of the vector and the second one as y value. If the conditions are not met, it returns false.

Parameters:

  • node The Node object to be decoded.
  • rhs The AGE::Vector2 that will store the decoded values.

Returns:

True if the decoding was successful, False otherwise.

function encode

Encodes a 2D vector into a Node object. 

static inline Node YAML::convert< AGE::Vector2 >::encode (
    const AGE::Vector2 & rhs
)

This function takes in a const reference to an AGE::Vector2 and encodes it into a Node object by pushing the x and y coordinates of the Vector2 onto the Node. The encoded Node is then returned.

Parameters:

  • rhs The 2D vector to be encoded.

Returns:

The encoded Node containing the x and y coordinates of the input Vector2.
