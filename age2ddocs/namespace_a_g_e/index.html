Parameters:

  • TMRC A reference to the TileMapRendererComponent that contains information about the active scene and the tile map being rendered.

  • layer A pointer to the tmx_layer structure representing the current layer being drawn.
  • Depth The depth of the current layer in the rendering hierarchy.
